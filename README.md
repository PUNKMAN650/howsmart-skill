# HowSmart Skill

HowSmart 是制造业数字化诊断与改造咨询 Skill，包含固定问卷、角色知识包、评估规则、运行脚本和空白资料模板。

- [下载 HowSmart Skill 0.3.7](https://github.com/PUNKMAN650/howsmart-skill/releases/tag/v0.3.7)
- [HowSmart 工作台](https://www.howsmart.xyz/)

在 Windows 启动 HowSmart 本机连接器，进入工作台的「本机运行」完成配对，再点击「安装 HowSmart Skill」。连接器校验发布包并安装到本机，之后的 Harness 会话会加载该版本。独立使用时可下载发布包，将完整的 howsmart 目录放到 Harness 配置的 Skill 搜索目录。

发布包只提供通用运行文件。企业材料、问答、报告与 API 密钥由使用者在本机管理。
